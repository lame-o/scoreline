# Linked match history and live odds

The native Mac app now shares one absolute-time domain and plot geometry between Win Probability and Timeline. Game-clock labels remain reported context, not an interpolated running clock. This preserves the real widths of stoppages, halftime, extra time and overtime.

## Behavior

- Soccer, football, basketball and baseball have a separate Timeline module in live and final pages, including existing college competitions. Odds and Timeline occupy the same column in wide layouts.
- Hover inspects a moment in both modules. Click holds it while incoming data continues. Previous/next key-event buttons explore history; Live/Latest clears the held selection. Arrow keys and VoiceOver actions support the same inspection.
- A single pointer object owns selection and the live Game/10 min window. Full-game finals use the same start/end bounds in both modules.
- Game context comes only from a play at or before the selection. Missing timestamps stay unplaced, and missing market samples are not backfilled from future prices. Soccer retains its match-minute fallback when absolute event timestamps are unavailable.
- Inspection is independent of broadcast playback. It does not rewind the live theater or alter the scoreboard. Existing goal replay and key-play actions remain separate.
- Polymarket outcome identity stays tied to the token/team. Near-tie endpoint labels retain their order until a clear reversal, then move without overlapping. Leaders are colored by outcome and cannot appear to join opposing lines. Interrupted endpoint glides do not create a false historical hook.
- One coalesced three-outcome update uses one timestamp. History responses retain live quotes received during the request.

## Data boundaries

Current CS2 rounds and climbing attempts have no comparable absolute event timestamps. Their existing round/attempt modules remain; this change does not invent a market-aligned chronology for them. Hockey is not in the current app catalog. Web work is outside this native update.

Some fixture captures omit team identifiers, so screenshot markers for those events correctly remain neutral. Provider timestamps are reporting timestamps and can be corrected to preserve chronology. The inspector labels adjusted event times. This is correlation in time, not a claim that a given play caused a price change.
